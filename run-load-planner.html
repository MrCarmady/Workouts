How this is calculated

ATL is fatigue, a 7-day weighted average of daily TSS. CTL is fitness, a 42-day weighted average. TSB is CTL minus ATL, often called form: positive means fresher, negative means carrying fatigue.

Each day: new ATL = ATL × e^(−1/7) + TSS × (1 − e^(−1/7)). New CTL = CTL × e^(−1/42) + TSS × (1 − e^(−1/42)). TSB is CTL minus ATL at the end of the same day.

For a target, the page assumes the same TSS every day for the number of weeks you choose, and solves for it directly. Targets that need negative TSS, or more than 150 TSS per day on average (1,050 per week), are rejected. In the plan above, a single day over 300 TSS is also rejected.
